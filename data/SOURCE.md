# 데이터 출처 및 이용 조건

이 프로젝트는 **개인의 비상업적 트레킹 기록 용도**로 만들어졌다.
아래 자료는 모두 제3자가 만든 것이며, 이 리포의 저작물이 아니다.

## 1. 남파랑길 GPX 노선 (`data/gpx_durunubi/`)

| 항목 | 내용 |
|---|---|
| **출처** | 두루누비 (한국관광공사) 코스 상세 페이지 — https://www.durunubi.kr/course-detail-view.do?crs_idx=… |
| **저작권** | 한국관광공사 및 각 코스 소관 지방자치단체 |
| **라이선스** | **공공누리 제4유형** — 출처표시 + 상업적이용금지 + **변경금지** |
| **받은 날** | 2026-10-18 |
| **받은 방법** | 리포 관리자가 90개 코스 상세 페이지에서 **브라우저로 직접** 받았다 |
| **파일 수** | 90개 (`남파랑길_1코스.gpx` ~ `남파랑길_90코스.gpx`, 받은 이름 그대로) · 15.5 MB · 124,173점 |

### 왜 직접 받았나

두루누비 `robots.txt` 는 모든 자동 수집기에 `/download` 를 막아 두었다(2026-10-18 재확인).
GPX 다운로드가 그 경로라서 스크립트로 받지 않았다. 사람이 브라우저에서 받는 것은 이 규칙의
대상이 아니다. 받을 페이지 목록만 공식 목록 데이터(`data/reference/durunubi-courses.json`)로 만들었다.

### 라이선스 준수 — 공개 리포에 올려도 되는가

공공누리 제4유형은 출처를 표시하면 **복제·배포·공중송신을 허용**하고, 상업적 이용과
**변경(2차적저작물 작성)** 을 금지한다. 비상업 공개 리포에 원본을 그대로 두는 것은 허용 범위다.

| 조건 | 이 리포의 대응 |
|---|---|
| 출처표시 | `data/gpx_durunubi/README.md`, 이 문서, README, 앱 지도 하단 표기 |
| 상업적 이용금지 | 개인 비상업 용도. 광고·유료 기능 없음 |
| 변경금지 | 파일을 한 바이트도 고치지 않는다. SHA1 을 `data/raw/durunubi-gpx.json` 에 남겼다 |

사실만 적어 둔다: 앱이 쓰는 `public/data/` 의 선은 원본 좌표를 **화면 표시용으로 줄인 것**(점 단순화)이고,
고도·거리·소요시간은 그 좌표로 **계산한 값**이다. 원본 파일과 별개로 만들어지며 원본은 그대로 남는다.
이것이 공공누리의 "변경"에 해당하는지는 해석의 문제이고, 나는 법률 판단을 할 위치가 아니다.
코스 메타데이터(3번)도 같은 방식으로 다뤄 왔다. **한국관광공사나 소관 기관이 요청하면 즉시 삭제한다.**

리포의 앱 소스 코드는 MIT 지만(README) 이 폴더는 제외된다. 이 폴더의 파일에는 공공누리 조건만 적용된다.

### 검증 결과 (`data/raw/durunubi-gpx.json`)

| 항목 | 결과 |
|---|---|
| 코스 번호 | 1~90 빠짐없음 |
| 총 거리 | **1,429.0 km** (공식 표기 합계 1,426.8 km, +0.15%) |
| 공식 거리와 2% 안쪽 | 60 / 90 코스 (5% 안쪽 86개, 가장 큰 차이 19·42·56·87코스 약 6%) |
| 시·종점 ↔ 공식 좌표 | 90개 모두 **69m 이내** |
| 코스 접합부 89곳 | 모두 **131m 이내** (중앙값 1m) |
| 세그먼트 | 90개 모두 표준 `<trkseg>` |
| 제작 도구(`creator`) | Korea Tourism Organization 62 · GPS Visualizer 20 · GPS TrackMaker 7 · MapSource 1 |

**86코스 파일에는 같은 노선이 트랙 2개로 들어 있다.** 둘 다 약 25km(공식 25km), 시·종점이 같고
경로는 최대 391m 차이 나는 두 판본이다. 이어 붙이면 64km 에 종점→시점 14km 직선이 생긴다.
원본은 고치지 않고, 파서(`scripts/lib/gpx.mjs`)가 시점이 같은 트랙이 반복되면 첫 트랙만 읽는다.

**공식 GPX 의 `<ele>` 는 쓰지 않는다.** 37개 코스에 고도가 빠진 점이 있고(55코스 26/614점),
49코스는 대부분 0, 5·51코스는 해수면 아래(-7m)로 내려간다. 고도는 5번의 DEM 값을 쓴다.

### 이전 노선 자료

2026-10-18 이전에는 라이선스가 명시되지 않은 비공식 노선 자료를 썼다. 공식 GPX 로 바꾸면서
그 자료와 수집 기록, 그 자료에 의존하던 스크립트(고도 캘리브레이션)를 리포에서 모두 지웠다.
git 이력에는 남아 있다.

### 수집 방법과 준수 사항

- `robots.txt`가 `Allow: /`로 허용한 **공개 HTML 페이지에서 렌더된 수치만** 읽었다
- 해당 사이트의 `robots.txt`는 `/api/`를 전면 차단하고 `ClaudeBot`·`Claude-User`·`anthropic-ai`를
  명시적으로 지정해 두었다. **이를 확인한 뒤 API 접근을 중단했다**
- **GPX 노선 데이터는 받지 않았고 사용하지도 않는다.** 이 프로젝트의 노선은 100% 위 1번 자료다
- 숫자 90쌍을 참고 지표로만 쓰며, 이 자료를 우리 산출물로 재배포하지 않는다

## 3. 코스 메타데이터 (`data/courses.meta.csv`, `data/reference/durunubi-courses.json`)

| 항목 | 내용 |
|---|---|
| **출처** | 두루누비 (한국관광공사) — https://www.durunubi.kr/namparang-course-list.do |
| **수집 경로** | 사이트가 목록을 채우는 데 쓰는 `/api/course/list?type=DNWW&serviceFlag=NA` |
| **수집일** | 2026-08-27 |
| **내용** | 90개 코스 × (시점·종점 지점명·주소·교통편, 시군, 공식 거리·소요시간·난이도, 코스 설명) |
| **라이선스** | **공공누리 제4유형** — 출처표시 + 상업적이용금지 + **변경금지** |

> 상세 페이지에 명시된 문구: *"한국관광공사에서 제작한 본 공공저작물은 공공누리
> '출처표시+상업적이용금지+변경금지' 조건에 따라 이용할 수 있습니다."*
>
> **변경금지 조건이 있다.** 이 프로젝트는 공식 텍스트(`travelerInfo`)를 파싱해
> 필드로 재구성하고 `public/data/courses.json` 에 담아 공개 리포에 올린다.
> 이것이 "변경"에 해당하는지는 해석의 문제이고, 나는 법률 판단을 할 위치가 아니다.
> 사실만 적어둔다: **출처는 표기했고, 상업적 이용은 하지 않으며, 원본 응답을
> `data/reference/durunubi-courses.json` 에 그대로 보관했다.** 한국관광공사가
> 요청하면 즉시 삭제한다 (문의처: 각 코스의 `koglContact`).

### robots.txt 준수

- `robots.txt` 의 `User-agent: *` 가 차단한 경로는 `/api/campaign/...`, `/api/dmzadmin`,
  `/api/dmz`, `/api/poi/main`, `/api/tracking`, `/dmzadmin`, `/download`, `/KTO/`,
  `travelRoad.do`, `travelRoadV2.do`, `saveBeforeLogin.do` 다.
  **우리가 쓴 `/api/course/list` 와 목록 페이지는 차단 대상이 아니다.**
- **`/download` 가 차단되어 있어 GPX 는 스크립트로 받지 않았다.** 2026-10-18 리포 관리자가
  브라우저에서 직접 받았다(1번 참조).
- 메타데이터 수집 요청은 총 3회(목록 페이지 1 + API 2)만 보냈다. 2026-10-18 에는 `robots.txt`
  재확인 1회와 목록 페이지 1회(상세 페이지 주소 형식 확인)를 보냈다.

### 공식 GPX 를 자동으로 받을 수 없다 (2026-08-27 확인 → 2026-10-18 직접 받아 해결)

두루누비의 노선 GPX 를 자동으로 받으려 했으나 두 경로 모두 막혀 있다. 그래서 2026-10-18
사람이 직접 받는 방식으로 바꿨다(1번).

| 경로 | 결과 |
|---|---|
| `gpx_src` (`/data/koreamobility/course/summap/*.gpx`) | **HTTP 404** — 직접 접근 불가 |
| 상세 페이지의 실제 다운로드 (`/download?filePath=...`) | **`robots.txt` 가 `/download` 를 차단** |

목록 API 도 좌표는 **시작·종료 4개 값만** 준다. 경로 폴리라인이 없다.
따라서 목록 데이터만으로는 지도에 선을 그릴 수 없다.

### 이용 방침

- 공공기관(한국관광공사)이 공개한 관광 정보다. 출처를 표기하고 개인 비상업 용도로만 쓴다.
- 원본 응답을 `data/reference/durunubi-courses.json` 에 그대로 보관해 재현 가능하게 했다.
- 노선도 공식 GPX 라 90개 코스 모두 공식 지점명·주소·교통편을 쓴다. 공식 안내문의 명백한 오타
  3곳은 구조화된 주소 필드로 확인해 고쳤다(`data/courses.meta.csv` 머리말에 기록).

## 5. 고도 데이터 (`data/cache/ele/`)

| 항목 | 내용 |
|---|---|
| **출처** | SRTM 30m DEM (NASA/USGS), opentopodata.org 공개 API 경유 |
| **정확도** | 수직 오차 **±16m 수준** |
| **표기** | 앱 화면에 "고도는 DEM 추정값" 각주를 표시한다 |

**모든 고도 지표는 DEM 으로 산출한 추정값**이다. 공식 GPX 의 `<ele>` 는 코스마다 누락·0값이
있어 쓰지 않는다(1번 검증 결과). 캐시 파일마다 원본 GPX 의 SHA1(`sourceSha1`)을 남겨,
노선이 바뀌면 해당 코스만 다시 조회한다.

스무딩·임계값(`scripts/lib/config.mjs`)은 2026-08 실측 고도가 있던 5개 코스로 캘리브레이션해 정했다.
그 대조군 자료는 이전 노선 자료와 함께 지웠으므로, 상수와 근거 표는 기록으로만 남는다.

소요시간은 두루누비 공식 권장 소요시간이다. 네이스미스 규칙 계산값은 참고용(`naismithMin`)으로만 둔다.
