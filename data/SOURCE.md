# 데이터 출처 및 이용 조건

이 프로젝트는 **코리아둘레길 개인 트레킹 기록 용도**(비상업)로 만들어졌다.
아래 자료는 모두 제3자가 만든 것이며, 이 리포의 저작물이 아니다.

## 0. 길별 범위

코리아둘레길 4개 길은 모두 같은 출처(두루누비, 한국관광공사)에서 같은 방법으로 받고,
같은 이용 조건(공공누리 제4유형)을 지킨다. 길마다 다른 것은 출처 페이지와 저장 위치뿐이다.

| 길 | 두루누비 코스 목록 | GPX 원본 | 코스 기록 | 상태 |
|---|---|---|---|---|
| 남파랑길 | https://www.durunubi.kr/namparang-course-list.do | `data/gpx_durunubi/` | `data/durunubi/namparang.json` | 수집 중 (90개) |
| 해파랑길 | https://www.durunubi.kr/haeparang-course-list.do | `data/durunubi/gpx/haeparang/` | `data/durunubi/haeparang.json` | 예정 (50개) |
| 서해랑길 | https://www.durunubi.kr/seohaerang-course-list.do | `data/durunubi/gpx/seohaerang/` | `data/durunubi/seohaerang.json` | 예정 (109개) |
| DMZ 평화의 길 | https://www.durunubi.kr/dmz-course-list.do | `data/durunubi/gpx/dmz/` | `data/durunubi/dmz.json` | 예정 (48개) |

길 정의(공공 API `routeIdx`, 사이트 `serviceFlag`)는 `scripts/lib/trails.mjs`. 아래 1·3번의 검증 수치와
예시는 지금 수집 중인 남파랑길 기준이다. 다른 길을 붙이면 그 길의 검증 결과를 같은 형식으로 더한다.

## 1. GPX 노선 — 남파랑길 (`data/gpx_durunubi/`)

| 항목 | 내용 |
|---|---|

| **저작권** | 한국관광공사 및 각 코스 소관 지방자치단체 |
| **라이선스** | **공공누리 제4유형** — 출처표시 + 상업적이용금지 + **변경금지** (두루누비 표기. 공공데이터포털 API 는 "제한 없음" — 더 엄격한 쪽을 지킨다, 3번 참조) |
| **처음 받은 날** | 2026-10-18 (이후 매주 자동 점검, 바뀐 코스만 다시 받음) |
| **파일 수** | 90개 (`남파랑길_1코스.gpx` ~ `남파랑길_90코스.gpx`, 두루누비가 주는 이름 그대로) · 15.5 MB |
| **기록** | `data/durunubi/namparang.json` — 코스별 GPX 경로 · SHA1 · 크기 · 연결성 점검 결과 |

### 어떻게 받나 — `npm run sync:durunubi` (매주 GitHub Actions)

공공데이터포털 "한국관광공사 두루누비 정보 서비스" 의 코스 목록(`courseList`)이 코스마다 GPX 주소
(`gpxpath` = `https://www.durunubi.kr/editImgUp.do?filePath=…`)를 준다. 그 주소로 받는다.
두루누비 `robots.txt` 가 막은 경로는 `/download` 이고 이 경로는 막혀 있지 않다. 받은 파일은
사이트 상세 페이지에서 직접 받은 것과 **바이트 단위로 같다**(2026-10-18, 90개 SHA1 일치).

공공 API 에 없는 코스(46개)는 두루누비 사이트 코스 목록(3번)이 같은 형식의 GPX 경로를 준다.
GPX 변경 감지와 연결성 점검 방법은 README "코스 데이터 갱신" 참조.

### 라이선스 준수 — 공개 리포에 올려도 되는가

공공누리 제4유형은 출처를 표시하면 **복제·배포·공중송신을 허용**하고, 상업적 이용과
**변경(2차적저작물 작성)** 을 금지한다. 비상업 공개 리포에 원본을 그대로 두는 것은 허용 범위다.

| 조건 | 이 리포의 대응 |
|---|---|
| 출처표시 | `data/gpx_durunubi/README.md`, 이 문서, README, 앱 지도 하단 표기 |
| 상업적 이용금지 | 개인 비상업 용도. 광고·유료 기능 없음 |
| 변경금지 | 파일을 한 바이트도 고치지 않는다. SHA1 을 `data/durunubi/namparang.json` 에 남긴다 |

사실만 적어 둔다: 앱이 쓰는 `public/data/` 의 선은 원본 좌표를 **화면 표시용으로 줄인 것**(점 단순화)이고,
고도·거리·소요시간은 그 좌표로 **계산한 값**이다. 원본 파일과 별개로 만들어지며 원본은 그대로 남는다.
이것이 공공누리의 "변경"에 해당하는지는 해석의 문제이고, 나는 법률 판단을 할 위치가 아니다.
코스 메타데이터(3번)도 같은 방식으로 다뤄 왔다. **한국관광공사나 소관 기관이 요청하면 즉시 삭제한다.**

리포의 앱 소스 코드는 MIT 지만(README) 이 폴더는 제외된다. 이 폴더의 파일에는 공공누리 조건만 적용된다.

### 검증 결과 (2026-10-18)

동기화가 GPX 를 받을 때마다 접합부·시종점 거리를 다시 재서 `data/durunubi/namparang.json` 의 `checks` 에 쓴다.

| 항목 | 결과 |
|---|---|
| 코스 번호 | 1~90 빠짐없음 |
| 총 거리 | **1,429.0 km** (공식 표기 합계 1,426.8 km, +0.15%) |
| 공식 거리와 2% 안쪽 | 60 / 90 코스 (5% 안쪽 86개, 가장 큰 차이 19·42·56·87코스 약 6%) |
| 시·종점 ↔ 공식 좌표 | 90개 모두 **69m 이내** |
| 코스 접합부 89곳 | 모두 **131m 이내** (중앙값 1m) |
| 세그먼트 | 90개 모두 표준 `<trkseg>` |
| 제작 도구(`creator`) | Korea Tourism Organization 62 · GPS Visualizer 20 · GPS TrackMaker 7 · MapSource 1 |

**86코스 파일에는 같은 노선이 트랙 2개로 들어 있다.** 둘 다 약 25km(공식 25km), 시·종점이 같고
경로는 최대 391m 차이 나는 두 판본이다. 이어 붙이면 64km 에 종점→시점 14km 직선이 생긴다.
원본은 고치지 않고, 파서(`scripts/lib/gpx.mjs`)가 시점이 같은 트랙이 반복되면 첫 트랙만 읽는다.

**공식 GPX 의 `<ele>` 는 쓰지 않는다.** 37개 코스에 고도가 빠진 점이 있고(55코스 26/614점),
49코스는 대부분 0, 5·51코스는 해수면 아래(-7m)로 내려간다. 고도는 5번의 DEM 값을 쓴다.

## 3. 코스 메타데이터 (`data/durunubi/<길>.json`, 보정 `data/courses.meta.csv`)

| 항목 | 내용 |
|---|---|
| **출처 ①** | 공공데이터포털 **한국관광공사 두루누비 정보 서비스** — `https://apis.data.go.kr/B551011/Durunubi` (`routeList`, `courseList`) |
| **출처 ②** | 두루누비 사이트 코스 목록 `/api/course/list?type=DNWW&serviceFlag=<길>` (남파랑 `NA` · 해파랑 `HE` · 서해랑 `SEO` · DMZ `DMZ`) — ①에 없는 코스 보충 |
| **우선순위** | ①에 있는 코스는 ① 값을 쓴다. 거리만 ①이 정수 반올림이라 같은 값이면 ②의 소수 값을 쓴다 |
| **갱신** | 매주 자동 (①의 데이터 갱신 주기는 일 1회) |
| **내용** | 코스명 · 거리 · 소요시간 · 난이도 · 행정구역 · 여행자정보(시점·종점·교통편) · 설명 · GPX 경로 |
| **인증키** | ①은 공공데이터포털 인증키가 필요하다. 리포에 넣지 않는다 — 로컬 `.env`, CI 는 Secret `DURUNUBI_SERVICE_KEY` |
| **이용 조건** | ① 공공데이터포털 표기: **이용허락범위 제한 없음** (2026-10-18 확인) · ② 두루누비 코스 페이지 표기: **공공누리 제4유형** |

**이 리포는 더 엄격한 공공누리 제4유형(출처표시 + 상업적이용금지 + 변경금지)을 기준으로 지킨다.**
같은 자료(같은 코스 ID·GPX 경로·안내문)를 두루누비 사이트는 제4유형으로 표기하고, ②로 보충한 코스(남파랑길 46개 등)는
①을 거치지 않는다. 제4유형을 지키면 "제한 없음" 조건도 함께 충족되므로, 출처별로 다르게 다루지 않는다.

**① 공공 API 에는 코스가 절반가량만 있다** (2026-10-18: 남파랑길 44/90, 해파랑길 43/50, 서해랑길 51/109,
DMZ 평화의 길 34/48). 빠진 코스에 규칙이 없어 ②로 보충한다. 겹치는 코스는 두 출처의 GPX 경로·소요시간·
난이도·여행자정보가 모두 같았고, 행정구역만 일부 다르다(남파랑길은 3코스 하나 — ① '부산 영도구', ② '부산 서구').
②는 공식 문서가 없는 사이트 내부 API 라 예고 없이 바뀔 수 있다. 바뀌면 주간 점검이 실패해 알 수 있다.

> 상세 페이지에 명시된 문구: *"한국관광공사에서 제작한 본 공공저작물은 공공누리
> '출처표시+상업적이용금지+변경금지' 조건에 따라 이용할 수 있습니다."*
>
> **변경금지 조건이 있다.** 이 프로젝트는 공식 텍스트(`travelerInfo`)를 파싱해
> 필드로 재구성하고 `public/data/courses.json` 에 담아 공개 리포에 올린다.
> 이것이 "변경"에 해당하는지는 해석의 문제이고, 나는 법률 판단을 할 위치가 아니다.
> 사실만 적어둔다: **출처는 표기했고, 상업적 이용은 하지 않으며, 받은 값을
> 길별로 `data/durunubi/<길>.json` 에 보관한다.** 한국관광공사가 요청하면 즉시 삭제한다.

### robots.txt 준수

- `robots.txt` 의 `User-agent: *` 가 차단한 경로는 `/api/campaign/...`, `/api/dmzadmin`,
  `/api/dmz`, `/api/poi/main`, `/api/tracking`, `/dmzadmin`, `/download`, `/KTO/`,
  `travelRoad.do`, `travelRoadV2.do`, `saveBeforeLogin.do` 다.
  **우리가 쓰는 `/api/course/list`·`/api/course/count`, 목록 페이지, GPX 경로 `/editImgUp.do` 는 차단 대상이 아니다.**
- **`/download` 는 쓰지 않는다.** GPX 는 공공 API 가 안내하는 `/editImgUp.do` 경로로 받는다.
- 주간 점검 요청량(켜진 길마다): 공공 API 1~2회, 사이트 목록 2회, GPX 크기 확인(HEAD) 코스당 1회, 바뀐 GPX 다운로드.
  요청 사이에 간격을 둔다.

### 이용 방침

- 공공기관(한국관광공사)이 공개한 관광 정보다. 출처를 표기하고 개인 비상업 용도로만 쓴다.
- 지점명·주소·교통편은 여행자정보(`travelerInfo`)에서 자동으로 뽑는다. 공식 안내문의 명백한 오타만
  `data/courses.meta.csv` 로 고친다(근거는 그 파일 머리말). 공식 자료가 고쳐지면 그 줄을 지운다.

## 5. 고도 데이터 (`data/cache/ele/`)

| 항목 | 내용 |
|---|---|
| **출처** | SRTM 30m DEM (NASA/USGS), opentopodata.org 공개 API 경유 |
| **정확도** | 수직 오차 **±16m 수준** |
| **표기** | 앱 화면에 "고도는 DEM 추정값" 각주를 표시한다 |

**모든 길의 고도 지표는 DEM 으로 산출한 추정값**이다. opentopodata 공개 API 는 하루 1,000회까지라
길을 처음 붙일 때 조회량을 미리 계산한다(TRAILS.md 2절). 공식 GPX 의 `<ele>` 는 코스마다 누락·0값이
있어 쓰지 않는다(1번 검증 결과). 캐시 파일마다 원본 GPX 의 SHA1(`sourceSha1`)을 남겨,
노선이 바뀌면 해당 코스만 다시 조회한다.

스무딩·임계값(`scripts/lib/config.mjs`)은 2026-08 실측 고도가 있던 5개 코스로 캘리브레이션해 정했다.
그 대조군 자료는 이전 노선 자료와 함께 지웠으므로, 상수와 근거 표는 기록으로만 남는다.

소요시간은 두루누비 공식 권장 소요시간이다. 네이스미스 규칙 계산값은 참고용(`naismithMin`)으로만 둔다.
